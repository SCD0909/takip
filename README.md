# takip

Şifre korumalı yatırım takip sitesi (Atık Sevk & Depolama, PYROROTOR, Cl Bypass). GitHub Pages üzerinden yayınlanır.

## Nasıl çalışır

- `index.html` sayfanın **şifrelenmiş** halidir (AES-256, [StatiCrypt](https://github.com/robinmoisson/staticrypt) ile).
- Depo herkese açık olsa da içerik şifresiz okunamaz; sayfa ancak doğru şifre girildiğinde tarayıcıda açılır.
- Şifre bu depoda **yer almaz**.
